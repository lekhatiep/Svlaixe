# SVLaixe

A modern ASP.NET Core application built with Web API capabilities for managing exam questions, answers, explanations, categories, and exam submission logic.

## About

`SVLaixe` is designed to support interactive learning and assessment workflows. The solution is ASP.NET Core backend to expose RESTful APIs for working with exam content and evaluating user responses.

The application includes:
- Question and category management
- Answer and explanation loading from JSON files
- Random question generation
- Exam result calculation
- API endpoints for retrieving and validating assessment data

This project is intended to provide a clean, maintainable architecture for educational or assessment-related systems.

## Technologies

This solution uses the following technologies and frameworks:

- .NET 8
- C# 12
- ASP.NET Core
- Blazor
- RESTful API development with `Controllers`
- Repository pattern with `Repositories`
- JSON-based data seeding/import
- Dependency injection
- Dapper
- Swagger / OpenAPI support (if configured in the project)
